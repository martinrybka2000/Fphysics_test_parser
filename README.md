# Fphysics_test_parser
Repository for testing parser in C++

## To run the code:
1. Git clone the repo 
2. cd the repo folder
3. execute commands ( if make does not work got to 4.)
```
mkdir build && cd build/
```
```
cmake .. && make
```
```
./Fphyscs_test_my_parser 
```
4. Delete everything in build/ directory and try: **make sure that you have gcc and g++ instaled**
```
cmake -G "Unix Makefiles" ..
```
```
make
```
```
./Fphyscs_test_my_parser 
```
Or
```
./Fphyscs_test_my_parser.exe 
```
